# Web3 Project Research Workflow

## Workflow

1. Identify official sources: website, docs, repository, official social channels.
2. Map project: product, chain, users, investors, ecosystem.
3. Check risks: fake sites, token scams, malicious contracts, unrealistic claims.
4. Review tasks: only public and official tasks; no bypassing rules.
5. Wallet safety: separate wallet, minimal funds, verify signature and approval.
6. Track freshness: TGE, points, tasks, deadlines are current facts.
7. Output neutral report; no guarantee of reward.
