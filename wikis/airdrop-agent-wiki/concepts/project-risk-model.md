# Web3 Project Risk Model

## Purpose

为 Web3 项目研究和空投信息整理提供安全、合规、可核验的风险框架。

## When to use

用于项目背景研究、公开任务核对、钱包安全检查、签名风险解释和信息可信度分级。

## Core rules

1. 不承诺收益、空投资格、TGE 时间、融资事实或代币价格。
2. 不提供 Sybil 规避、刷量、批量号、假身份、绕平台规则或垃圾互动方法。
3. 任何项目状态、任务规则、融资、TGE、快照和奖励规则均为 `needs-source-update`。
4. 钱包签名、授权、跨链和连接 dApp 必须提示人工确认和最小风险。

## Workflow

1. 来源分级：官网、官方文档、合约、公告、社媒、第三方媒体分别标注。
2. 项目基础：团队、产品、链、合约、生态、文档、代码和公开路线图。
3. 任务风险：是否要求资金、签名、授权、下载软件、邀请或身份信息。
4. 钱包风险：授权范围、合约地址、钓鱼域名、仿冒社媒和撤销授权路径。
5. 输出结论：只做研究摘要、风险等级和待核验清单。

## Edge cases

- 官方账号被盗或域名被劫持时，单一来源仍不可靠。
- 合约开源不代表安全，审计报告也可能过期。
- 空投任务可能随时间变化，旧教程不能当作当前规则。

## Validation checks

- 是否拒绝刷量、规避风控和假身份？
- 是否把 TGE、融资、快照、奖励规则标记为需要核验？
- 是否包含钱包签名和授权风险？

## Source notes

项目公告、任务规则、合约地址、快照、TGE、融资、空投资格和平台政策均需实时核验。
