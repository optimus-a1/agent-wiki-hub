# Contract Review Checklist

## Purpose

提供合同初步审阅清单，帮助识别信息缺口、条款风险和需要律师确认的问题。

## When to use

用于商业合同、服务协议、采购协议、保密协议、劳动相关文本和平台协议的非法律意见式审阅。

## Core rules

1. 只提供信息、清单和风险提示，不给最终法律意见。
2. 司法辖区、法律条文、监管要求和判例均为 `needs-source-update`。
3. 高风险条款必须建议合格律师或法务人工确认。
4. 不代替签署、谈判或合规审批。

## Workflow

1. 基础信息：主体、签署权限、日期、期限、适用法律、争议解决。
2. 商业条款：标的、价格、付款、交付、验收、税费和发票。
3. 风险条款：违约、赔偿、责任上限、解除、保密、知识产权和不可抗力。
4. 操作条款：通知、变更、转让、审计、数据处理和终止后义务。
5. 输出：风险清单、缺失信息、待谈判点和律师确认点。

## Edge cases

- 跨境、劳动、金融、医疗、数据出境和知识产权交易风险更高。
- 标准平台协议通常不可谈判，但仍需识别风险。
- 合同语言版本冲突要明确优先文本。

## Validation checks

- 是否声明非法律意见？
- 是否标记法律和司法辖区为需要更新？
- 是否输出人工律师确认点？

## Source notes

法律条文、判例、监管规则、平台协议和司法辖区要求均需实时核验。
