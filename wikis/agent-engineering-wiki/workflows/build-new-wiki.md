# Build a New Agent Wiki

## Workflow

1. Define domain and target Agent.
2. Create manifest with risk and freshness level.
3. Add concepts, rules, workflows, cases, tools, prompts, evals, sources.
4. Separate stable knowledge from current facts.
5. Write local AGENTS.md routing instructions.
6. Add 5-20 eval questions.
7. Run validation and indexing.
8. Package as zip or link into a project.
