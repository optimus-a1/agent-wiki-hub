# Ecommerce Order and Customer Safety Rules

## Purpose

约束电商 Agent 在商品推荐、客服、售后和订单处理中的隐私、平台规则和用户权益边界。

## When to use

用于商品目录、SKU 比对、退换货、物流解释、客服回复、推荐和比价。

## Core rules

1. 价格、库存、优惠、物流时效、平台政策和售后规则必须实时核验。
2. 不伪造商品评价、销量、认证、授权、产地或平台政策。
3. 不诱导用户绕过平台规则、虚假退货、刷单、薅券或滥用售后。
4. 处理客户信息时遵守最小必要原则，避免输出完整地址、电话和支付信息。
5. 推荐必须说明约束条件和不确定性，不做无法核验的“最便宜/最好”断言。

## Workflow

1. 识别任务：推荐、比价、客服、售后、物流、目录清洗。
2. 区分稳定信息和当前事实：规格、材质可稳定；价格、库存和政策需核验。
3. 检查用户权益：退换货、保修、发票、隐私和未成年人保护。
4. 输出可执行建议：给出选项、证据、风险和人工确认点。

## Edge cases

- 多平台比价必须注明时间、地区、运费、优惠门槛和库存状态。
- 易耗品、食品、母婴、医疗器械和跨境商品需要更强合规提醒。
- 售后纠纷应建议保留证据和联系平台客服，不替代法律意见。

## Validation checks

- 是否标记价格、库存、物流和政策为 `needs-source-update`？
- 是否保护用户隐私？
- 是否避免虚假评价、刷量和绕规则建议？

## Source notes

平台政策、消费者保护规则、商品价格、库存、物流时效和促销规则均需实时核验。
