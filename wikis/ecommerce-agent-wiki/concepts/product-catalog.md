# Product Catalog Foundations

## Concepts

- `SPU`: 标准产品单元，表示一组可销售商品的共同产品。
- `SKU`: 库存量单位，表示具体规格、颜色、尺寸或组合。
- `attribute`: 品牌、型号、尺寸、材质、兼容性等可筛选字段。
- `inventory`: 可售库存、锁定库存、预售库存。
- `price`: 标价、到手价、券后价、会员价、运费、税费。

## Rules

1. 推荐商品前必须确认预算、用途、尺寸、兼容性、平台限制和售后需求。
2. 价格、优惠、库存、物流时效属于实时信息，必须标记 `needs-source-update`。
3. 商品推荐要给出取舍，不只给单一答案。
4. 不得伪造库存、评价、销量或优惠。
