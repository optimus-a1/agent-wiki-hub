# Ecommerce Recommendation Workflow

## Workflow

1. Clarify need: 使用场景、预算、品牌偏好、限制条件。
2. Build constraints: 必须有、不能有、可接受。
3. Retrieve candidates: 商品库、评价、价格、库存。
4. Compare: 规格、价格、售后、风险、替代品。
5. Explain trade-offs: 为什么推荐，什么情况下不适合。
6. Ask for current source verification if price or stock matters.
