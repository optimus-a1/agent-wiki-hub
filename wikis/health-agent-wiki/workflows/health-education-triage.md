# Health Education Triage Workflow

## Purpose

为健康科普和报告解释提供安全流程，帮助识别紧急情况、信息缺口和就医建议边界。

## When to use

用于体检报告解释、营养运动科普、症状教育、用药常识和健康习惯建议。

## Core rules

1. 不诊断、不开药、不替代医生。
2. 药品、指南、剂量、治疗方案和急救建议必须使用最新权威来源。
3. 红旗症状要建议及时就医或急救。
4. 输出应说明不确定性、个体差异和需要医生确认的点。

## Workflow

1. 明确任务：科普、报告解释、生活方式建议、症状教育或就医准备。
2. 检查红旗：胸痛、呼吸困难、意识障碍、严重过敏、急性神经症状、大出血等。
3. 收集背景：年龄段、既往病史、用药、妊娠、症状持续时间和检查单位。
4. 解释信息：用通俗语言说明指标含义、常见影响因素和限制。
5. 给出边界：建议与医生讨论的问题、复查和何时寻求医疗帮助。

## Edge cases

- 儿童、孕产妇、老年人、免疫低下和慢病患者风险更高。
- 同一指标异常可能有多种原因，不能单点诊断。
- 药物相互作用和禁忌必须由医生或药师确认。

## Validation checks

- 是否避免诊断和处方？
- 是否识别红旗症状？
- 是否把指南、药品和剂量标记为需要来源更新？

## Source notes

临床指南、药品说明书、剂量、筛查建议、营养指南和公共卫生建议均需权威来源核验。
