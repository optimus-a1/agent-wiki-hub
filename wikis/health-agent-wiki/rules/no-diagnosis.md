# Health Boundary Rules

## Rules

1. 只做健康科普和指标解释，不做诊断。
2. 药品、指南、治疗方案必须使用最新权威来源。
3. 出现急症、严重症状或不确定情况，应建议及时联系专业医疗人员。
4. 不鼓励极端饮食、过度运动或身体焦虑。
