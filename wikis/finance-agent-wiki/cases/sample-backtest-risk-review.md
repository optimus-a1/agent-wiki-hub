# Sample Backtest Risk Review

## Purpose

提供一个可复用的回测审查样例，帮助 Agent 判断回测报告是否满足数据、成本、风控和上线边界要求。

## When to use

用于审查用户提供的策略回测摘要、模拟盘报告、因子测试结果或交易系统上线申请。

## Core rules

1. 回测结果只能作为研究和模拟依据，不能作为真实资金执行指令。
2. 必须检查数据质量、手续费、滑点、流动性、样本外测试和过拟合。
3. 必须输出风险等级、缺失项和人工确认点。
4. 最新费率、交易规则、行情和 API 参数必须标记 `needs-source-update`。

## Workflow

1. 读取策略假设：资产池、周期、信号、调仓频率和持仓约束。
2. 检查数据：来源、时间范围、缺失、异常、复权、时区和幸存者偏差。
3. 检查成交：手续费、spread、滑点、延迟、部分成交和容量约束。
4. 检查验证：训练/验证/样本外、滚动窗口、压力区间和参数敏感性。
5. 检查风险：最大回撤、回撤持续、连续亏损、杠杆、流动性和操作风险。
6. 输出审查结论：通过、条件通过、退回补充或禁止真实资金部署。

## Sample input

```text
策略：日频均线交叉
资产池：示例股票池
区间：2020-01-01 至 2025-12-31
报告结果：年化收益 28%，最大回撤 12%
成本设置：未说明
滑点设置：未说明
样本外测试：未说明
上线请求：直接接入真实账户自动交易
```

## Expected output

```text
审查结论：退回补充，禁止直接真实资金部署
用途边界：仅可作为研究或模拟盘候选
主要缺失：
- 未说明数据来源、缺失处理、复权方式和幸存者偏差处理
- 未计入手续费、spread、滑点、延迟和部分成交
- 未提供样本外测试、滚动窗口和参数敏感性
- 未评估流动性、容量、连续亏损和操作风险
风险等级：high
需要来源更新：
- 当前交易费率、税费、最小下单单位、交易规则和 API 参数
人工确认点：
- 是否允许进入模拟盘
- 风控阈值、日志、熔断和权限隔离是否验收
```

## Edge cases

- 如果用户提供实盘账户、API key 或私钥，应拒绝接收并改用安全配置说明。
- 如果策略使用杠杆或衍生品，应升级为高风险并要求更严格压力测试。
- 如果只有收益曲线没有交易明细，不应判定为可部署。

## Validation checks

- 是否拒绝直接真实资金执行？
- 是否指出数据、成本、样本外和过拟合缺口？
- 是否列出 `needs-source-update` 和人工确认点？

## Source notes

当前费率、税费、交易所规则、保证金规则、行情源和 API 参数均需联网或权威来源更新。
