# Finance Agent Wiki Overview

## Purpose

为 Agent 提供 `finance` 领域的稳定知识、执行流程、边界规则和评测标准。

## Knowledge types

- Concepts: 长期稳定的基本概念。
- Rules: 判断标准、安全边界和质量要求。
- Workflows: 可重复执行的任务步骤。
- Cases: 常见失败、边界情况和纠错样例。
- Tools: 工具/API/平台/数据格式说明。
- Prompts: 给 Agent 的角色和任务模板。
- Evals: 验收题和行为测试。
- Sources: 需要实时核验的信息清单。
