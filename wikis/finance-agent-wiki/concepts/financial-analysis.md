# Financial Analysis Foundations

## Purpose

提供财务分析的基础框架，帮助 Agent 区分会计事实、经营判断和估值假设。

## When to use

用于公司研究、财报摘要、估值框架、同业比较和风险提示。最新财报、审计意见、监管问询和公司公告必须实时核验。

## Core rules

1. 财务分析输出不得变成个人化买卖建议。
2. 使用财报数据时必须说明期间、币种、会计准则和是否经审计。
3. 估值指标只能作为研究工具，不能单独作为交易结论。
4. 对异常增长、一次性收益、关联交易和现金流背离要单独提示风险。

## Workflow

1. 利润表：检查收入、毛利、营业利润、净利润、一次性项目和利润质量。
2. 资产负债表：检查现金、应收、存货、固定资产、借款、负债期限和权益结构。
3. 现金流量表：检查经营现金流、投资现金流、筹资现金流和自由现金流。
4. 指标分析：计算毛利率、净利率、ROE、ROA、资产负债率、周转率和现金转换。
5. 估值分析：可使用 PE、PB、PS、EV/EBITDA、DCF 等框架，但要列出假设。
6. 交叉验证：利润增长是否被现金流支持，资产扩张是否带来收入，负债压力是否可持续。

## Edge cases

- 金融、地产、保险、资源品、平台型公司需要行业化指标，不能套用通用模板。
- 高增长公司可能利润为负，应说明收入质量、获客成本、留存和现金消耗。
- 跨国公司要注意汇率、地区披露和会计准则差异。

## Validation checks

- 是否说明数据期间、币种、准则和来源？
- 是否区分历史事实、分析判断和估值假设？
- 是否列出现金流、负债和一次性项目风险？
- 是否避免输出买卖指令或个人化仓位？
