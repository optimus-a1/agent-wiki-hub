# Finance Risk Control Rules

## Purpose

任何金融 Agent 都必须先做风险控制，再做收益分析。

## Non-negotiable rules

1. 默认只做教育、研究、模拟盘和风险检查。
2. 不输出针对个人的买入、卖出、杠杆、仓位建议。
3. 不自动执行真实资金交易；真实交易必须由成年人、合规账户和人工确认完成。
4. 所有策略说明都必须包含风险、失败条件、数据假设和不确定性。
5. 回测必须包含手续费、滑点、延迟、异常行情、缺失数据和样本外验证。
6. 对衍生品、杠杆、保证金、跨交易所转账等场景，必须标注高风险。

## Risk checklist

- 仓位风险：单资产、单行业、单策略和总组合暴露不得只按名义金额判断。
- 回撤风险：必须设定最大回撤、单日损失、连续亏损和暂停复盘阈值。
- 杠杆风险：标注保证金、强平、资金费率、借贷成本和跳空风险。
- 流动性风险：用成交量、盘口深度、spread、冲击成本和退出时间评估。
- 操作风险：错误参数、重复下单、权限过宽、日志缺失、告警失效。
- 交易所/API/账户风险：断连、限频、撮合失败、账户冻结、提现限制。
- 模型过拟合风险：参数过多、样本过小、数据泄漏、只报告最佳结果。
- 数据源错误风险：缺失、重复、错位、复权错误、幸存者偏差。
- 监管与税务风险：必须按用户所在司法辖区和交易场景实时核验。

## Position and drawdown guardrails

1. 仓位计算要区分名义仓位、净敞口、毛敞口、保证金占用和潜在最大损失。
2. 风险输出只能给教育性框架或模拟示例，不能给个人化仓位比例。
3. 回撤指标至少包含最大回撤、回撤持续时间、恢复时间和压力场景。
4. 杠杆策略必须先说明强平路径，再讨论收益。
5. 当流动性不足以支持退出时，策略应判定为不可部署或仅限模拟。

## Output requirements

金融输出必须包含：

```text
用途：教育/研究/模拟/风控检查
关键假设：...
主要风险：...
不可用场景：...
需要最新来源确认：...
```
