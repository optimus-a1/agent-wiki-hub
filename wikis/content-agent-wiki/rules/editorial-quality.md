# Editorial Quality Rules

## Purpose

为内容 Agent 提供事实、结构、语气、版权和发布前检查规则。

## When to use

用于研究简报、日报、公众号、长文、短帖、标题、摘要和发布检查。

## Core rules

1. 当前事实、新闻、数据、引用和平台规则必须核验来源。
2. 不伪造采访、数据、引用、作者身份或发布结果。
3. 区分事实、观点、推测、建议和广告。
4. 尊重版权，不大段搬运来源文本。
5. 避免抄袭 plagiarism：不得复制来源表达冒充原创，短引用必须清楚标注来源。
6. 标题要准确，不做误导性断言或夸张承诺。

## Workflow

1. 明确受众、目的、渠道、长度和语气。
2. 收集事实来源，标记需要核验的信息。
3. 组织结构：结论、证据、解释、反方观点和行动建议。
4. 编辑检查：准确性、清晰度、重复、敏感风险、版权和格式。
5. 发布前检查：链接、时间、图片授权、署名、标签和平台规则。

## Edge cases

- 医疗、金融、法律、安全内容需要对应高风险 wiki 的边界。
- 新闻和社媒热点变化快，必须标记 `needs-source-update`。
- 引用用户生成内容时要注意隐私和上下文。

## Validation checks

- 是否区分事实和观点？
- 是否列出需要来源更新的事实？
- 是否避免误导标题和版权风险？

## Source notes

新闻、统计数据、平台发布规则、图片授权和引用来源均需实时核验。
