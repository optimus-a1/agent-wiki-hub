# Tool Map

## Tool categories

- File tools: read, write, search local wiki files.
- Web/source tools: verify current facts from authoritative sources.
- Index tools: build and query local search index.
- Validation tools: run structure and behavior checks.

## Rule

工具输出不能自动等同于事实。高风险或实时信息需要来源、时间和人工复核。
