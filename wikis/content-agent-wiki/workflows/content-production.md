# Content Production Workflow

## Purpose

把选题、研究、写作、编辑、发布检查和复盘串成可复用流程。

## When to use

用于日报、周报、研究简报、品牌内容、社媒帖子、长文和知识卡片。

## Core rules

1. 先明确受众和渠道，再决定格式。
2. 关键事实必须可追溯；无法核验则标记 `needs-source-update`。
3. 输出必须符合渠道限制，但不能牺牲准确性。
4. 高风险领域内容必须保留人工确认点。

## Workflow

1. 选题：定义核心问题、读者收益、发布渠道和成功标准。
2. 研究：收集来源、提炼事实、记录不确定性。
3. 大纲：建立主线、段落顺序、证据和反方观点。
4. 初稿：清楚表达，不堆砌术语。
5. 编辑：删重复、改标题、查事实、统一风格。
6. 发布检查：格式、链接、图片、署名、敏感词、平台规则。
7. 复盘：阅读、互动、转化、错误更正和知识库更新。

## Edge cases

- 多渠道分发要为每个平台改写，不要机械复制。
- 赞助和推广内容要明确标识。
- 使用 AI 生成内容时要人工审校事实和版权风险。

## Validation checks

- 是否有受众、渠道和成功标准？
- 是否列出事实来源和待核验项？
- 是否完成发布前检查？

## Source notes

热点、数据、引用、平台规则、图片授权和品牌规范均为 `needs-source-update`。
