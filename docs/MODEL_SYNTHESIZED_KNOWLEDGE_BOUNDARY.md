# Model-Synthesized Knowledge Boundary

v2.1 knowledge pages are synthesized from general model knowledge. They are useful for agent behavior, checklists, workflows, and safe defaults.

They are not authoritative sources, citations, professional advice, current facts, or verified evidence.

Agents must disclose uncertainty, preserve source gates, and request human review when the task affects money, health, law, security, production systems, customs filings, wallets, privacy, or customer-impacting actions.
