# High Risk Domain Boundaries

High-risk domains retain human and source gates.

| Domain | Human Gate | Source Gate |
| --- | --- | --- |
| Finance | Real money, leverage, personalized advice, trading-system changes | Prices, fees, rules, taxes, market data |
| Legal | Jurisdiction-specific conclusions, filings, notices, contract positions | Laws, regulations, cases, regulator guidance |
| Health | Symptoms, diagnosis-like interpretation, dosage, treatment, emergency risk | Guidelines, drug labels, clinical advice |
| Security | Production remediation, secrets, access, detection coverage | CVEs, patches, advisories, detection rules |
| NodeOps | Production mutation, destructive commands, rollback, firewall changes | Versions, provider limits, chain parameters |
| Customs | Filing, classification, declaration, high-risk discrepancy acceptance | HS codes, tax rates, policy, supervision conditions |
| Airdrop/Web3 | Wallet signing, approvals, identity-sensitive actions | Project status, TGE, listing, snapshot, eligibility |

Stable wiki pages may describe principles and review workflows, but current facts require source review before use.
