# Obsidian Usage

Open Obsidian, choose `Open folder as vault`, select `obsidian-vault/`, then start with `05_Dashboard/Wiki Status.md` or `02_Knowledge/MOCs/`.

v2.1 adds `Knowledge Density.md`, `Current Fact Gates.md`, `Human Review Gates.md`, `High Risk Boundaries.md`, and `Knowledge Density Map.canvas`. All pages are readable as plain Markdown; Dataview and Bases are optional.
